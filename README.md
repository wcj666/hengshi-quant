# 衡势量化 V3.6.1 Mac 一键升级

当前项目使用 `main` 作为远程发布分支。仓库工作区启用提交后自动推送，完成一次优化提交后会自动推送到已配置的 GitHub 远程仓库。个人 `config.json`、持仓截图和 `output/` 运行数据始终由 `.gitignore` 排除。

1. 在 Mac 上下载并解压 
2. 双击解压文件夹内的 `安装_开机自动启动.command`（无需管理员权限）。安装程序需要 Python 3.11+；如果系统提示权限问题，可在 Finder 中对文件右键选择打开。
3. 依赖安装完成后，浏览器访问 `http://127.0.0.1:8765/`，必要时按 Command + Shift + R 强制刷新。
4. 使用 `检查网页版本.command` 核对「已安装程序版本」和「网页运行版本」，两者都应为 **3.6.1**。
5. 在总览查看三级预警/净值曲线，在左侧第二栏查看模拟减仓和人工成交日志，在第三栏查看报价质量。

旧版持仓、自选、现金、风险参数与手工锁定的止盈止损以已有 `config.json` 为准：安装器只更新程序文件。原有 `output` 里的历史日志也会保留。

**重要：** 这不是券商官方交易终端；没有逐笔行情保证，也不会自动下单。人工交易登记不改动真实或模拟持仓，交易后请分别核对并修改持仓和现金。数据异常时会停用新交易观察信号和减仓模拟。Mac需要登录并保持联网、唤醒状态。

如果网页仍是旧版，运行 `检查网页版本.command`，把终端显示的两个版本、8765端口进程以及 `~/Library/Application Support/AshareAB/app/output` 下的报错日志发来排查。不要删除配置文件。

### V3.6.1 新增诊断

- 安装前自动备份旧配置及已有的交易日志、净值日志到 `~/Library/Application Support/AshareAB/backups/`，不会改动原文件。
- 安装后检查网页与文件均显示 V3.6.1。
- 如遇行情超过7.5秒、价格冻结或没有新的买卖提醒，双击 `诊断行情状态.command`，检查源时间是否核验和接口错误。未经核验的价格仍可显示参考净值，但不会触发新的交易提示。


## 已展开的源码

完整源码现已直接放在仓库根目录，可浏览和逐文件修改。完整功能与配置说明见 [源码使用说明](SOURCE_SETUP.md)。

盘后复盘页面为 `http://127.0.0.1:8765/close-review`，用于查看减仓测算、现金预留和次日观察价。买入股数由盘中 V1 核验。

开源量化项目的对比与衡势的改造顺序见[工程优化路线](工程优化路线.md)。

首次从源码运行：

```bash
cp config.example.json config.json
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python web_dashboard.py --open
```

示例配置是无持仓的虚构账户。`config.json` 和 `output/` 仅在本地维护，已通过 `.gitignore` 排除。
